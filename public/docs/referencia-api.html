Referência de API

Webhooks: pedido, respostas e erros.

Endereços abaixo usam o placeholder https://<n8n>. Substitua pelo host da sua automação. Todos os webhooks usam POST com corpo JSON.

Resgatar presente

POSThttps://<n8n>/webhook/resgatar-presente

Pedido

JSON
{
  "campaignId": "campanha-goostozinhos-v1",
  "handleIg": "cliente_ig",
  "name": "Maria Silva",
  "phoneNumber": "5541999990001",
  "reviewDeclared": true
}
CampoRegra
campaignIdTexto. Ausente usa a campanha padrão.
handleIgObrigatório. Aceita com ou sem @; válido com A-Za-z0-9._, 1–30 caracteres. Persistido sem validação.
nameObrigatório, 2–80 caracteres após aparar espaços.
phoneNumberObrigatório. Dígitos com DDD brasileiro válido; 55 inicial opcional. Servidor normaliza para 55DDDNÚMERO.
reviewDeclaredObrigatório true (confirmação declarada da avaliação).

Respostas

HTTPstatusQuandoCorpo (campos principais)
200entregueNovo resgate com WhatsApp enviado, ou campanha de teste (com whatsapp: ignorado_teste)couponCode, code, validade, desconto, pedidoMinimo, whatsapp
200pendenteCupom garantido, WhatsApp falhouIguais + whatsapp: falhou, whatsappError.code, mensagem de nova tentativa
200ja_resgatadoTelefone já recebeu mensagem antescouponCode, code, validade, disponivel, vencido, desconto, pedidoMinimo
400invalid_requestNome, @, telefone ou confirmação inválidoserror amigável, sem dados pessoais
409indisponivelSem cupom ativo ou cupom desligado (telefone novo)error: Cupom indisponível
409cupom_vencidoCupom passou da validade (telefone novo)error: Cupom vencido
503erro_temporarioFalha de leitura/escrita nas tabelascode: upstream_unavailable, mensagem de nova tentativa

Exemplo de entregue:

JSON
{
  "status": "entregue",
  "couponCode": "GOOSTO10",
  "code": "GOOSTO10",
  "validade": "2026-11-30",
  "desconto": "10%",
  "pedidoMinimo": "30.00",
  "whatsapp": "enviado"
}

Notas:

  • Validade usa AAAA-MM-DD e vale até 23h59 de Brasília (UTC−3).
  • Respostas 200 de já resgatado refletem o estado atual do cupom (disponivel, vencido); a tela mostra aviso quando indisponível.
  • Chamada simultânea duplicada com o mesmo telefone: uma vence; a perdedora encerra sem resposta própria a confirmar.
  • Tempo-limite do navegador: 45 s. Tempo-limite de execução no servidor: consulte a Operação.

Importar cupom

POSThttps://<n8n>/webhook/importar-cupons

Cabeçalho de autenticação via credencial configurada no webhook (headerAuth; o nome exato do header vive na credencial, não no export). Guarde o segredo em variável de ambiente, nunca no código.

Pedido (exatamente um cupom)

JSON
{
  "cupons": [
    {
      "code": "GOOSTO-AMOR10",
      "campaignId": "campanha-goostozinhos-v1",
      "status": "novo",
      "discount_value": "10%",
      "expiration_date": "2026-11-30",
      "min_order_value": "30.00",
      "valid": true,
      "disponivel": true
    }
  ]
}

Aceita também a chave coupons ou o objeto direto. O código é convertido para maiúsculas. disponivel ausente vale true; qualquer valor não booleano rejeita.

Respostas

HTTPstatusQuando
200successCupom inserido (total: 1)
400invalidFormato inválido, data passada ou mais/menos de um cupom
401/403—Segredo ausente ou errado a confirmar
409duplicateCódigo já cadastrado
409campanha_com_cupom_ativoCampanha já tem cupom ativo

Checagem de Instagram (fora do resgate)

POSThttps://<n8n>/webhook/validar-instagram

Pedido: handleIg (ou handle) e campaignId opcional. Resposta 200 com is_follower, handleIg normalizado e mensagem; 400 quando o @ é inválido ou ausente. Este webhook não é chamado pela landing hoje.
